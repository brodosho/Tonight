# Read Me

### URL: <https://brodosho.github.io/Tonight/>

### Overview
**Tonight** picks a random episode from a TV show you've already seen all the episodes for. It's for those who like to rewatch shows more than a few times, or for those who want to experience what it was like when TV used to play any old episode.

### Stack
## **Frontend:** HTML5

### Why I built this
I am an avid TV show watcher, especially with sitcoms, and I miss the feeling of turning on the TV and not knowing which episode you're going to watch. I like piecing together context like it's a puzzle and I figure there are probably others just like me. I built this app to turn this concept into an interactive experience.

### "I want to use this myself"
This app is intended for mobile use. If you would like to use it, clone this repo, create a page and open the url in a browser that offers the option to add to your homescreen (Safari on iPhone).

### What's next for this app
I am hoping to create a server for this app, so that account creation can be made so your shows can be accessed from all different devices. I would also like to make experience more heavily gamified.
